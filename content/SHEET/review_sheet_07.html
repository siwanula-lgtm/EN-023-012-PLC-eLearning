📌 1. สาระสำคัญ

เซนเซอร์เป็นอุปกรณ์อินพุตที่ทำให้ PLC รับรู้สถานะของเครื่องจักร เซนเซอร์แบบดิจิทัลที่ใช้มากในงานวิศวกรรมเครื่องกล ได้แก่ ลิมิตสวิตช์ซึ่งต้องสัมผัสชิ้นงาน พร็อกซิมิตีเซนเซอร์แบบเหนี่ยวนำซึ่งตรวจจับโลหะ พร็อกซิมิตีเซนเซอร์แบบเก็บประจุซึ่งตรวจจับได้ทั้งโลหะและอโลหะ โฟโตอิเล็กทริกเซนเซอร์ซึ่งใช้ลำแสงตรวจจับวัตถุ และรีดสวิตช์ซึ่งตรวจตำแหน่งลูกสูบของกระบอกสูบ เซนเซอร์อิเล็กทรอนิกส์ 3 สายมีเอาต์พุตชนิด NPN ซึ่งต่อกับอินพุตแบบ Sink และชนิด PNP ซึ่งต่อกับอินพุตแบบ Source …

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 7.1 จำแนกชนิดของเซนเซอร์อุตสาหกรรมและหลักการทำงานได้
  • 7.2 ต่อเซนเซอร์ 2 สายและ 3 สายชนิด NPN/PNP เข้ากับอินพุตของ PLC ได้ถูกต้อง
  • 7.3 เลือกเซนเซอร์ให้เหมาะกับงานจากข้อมูลจำเพาะได้
  • 7.4 เขียนโปรแกรมใช้งานสัญญาณเซนเซอร์ในงานตรวจจับ นับ และตรวจความผิดปกติได้
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 7.1 เซนเซอร์ในระบบควบคุมเครื่องจักร
  • 7.2 พร็อกซิมิตีเซนเซอร์
  • 7.3 โฟโตอิเล็กทริกเซนเซอร์และรีดสวิตช์
  • 7.4 การต่อเซนเซอร์เข้ากับพีแอลซี
  • 7.5 การเลือกเซนเซอร์และการประยุกต์ในโปรแกรม
📝 4. บทสรุป

เซนเซอร์ดิจิทัล: ลิมิตสวิตช์ (สัมผัส) พร็อกซิมิตีเหนี่ยวนำ (โลหะ) เก็บประจุ (ทุกวัสดุ) โฟโต (แสง) รีดสวิตช์ (แม่เหล็ก) ระยะตรวจจับวัดจากเหล็กกล้า วัสดุอื่นคูณตัวลดระยะ ติดตั้งไม่เกินประมาณ 80% ของระยะ โฟโต 3 แบบ: ลำแสงผ่าน (ไกลสุด) สะท้อนกลับ (ฝั่งเดียว+แผ่นสะท้อน) สะท้อนจากวัตถุ (สั้น ขึ้นกับสี) สาย 3 สาย: น้ำตาล +V ฟ้า 0 V ดำ เอาต์พุต · NPN → Sink · PNP → Source ใช้สัญญาณเซนเซอร์ร่วมกับไทเมอร์ เคาน์เตอร์ และเงื่อนไขตรรกะ สัญญาณแอนะล็อก 4–20 mA ผ่านโมดูลแอนะล็อก

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงอธิบายหลักการทำงานของพร็อกซิมิตีเซนเซอร์แบบเหนี่ยวนำและแบบเก็บประจุ และบอกวัสดุที่ตรวจจับได้
  • พร็อกซิมิตีเซนเซอร์ Sn = 12 มม. ต้องตรวจจับชิ้นงานทองเหลือง (ตัวคูณ 0.45) …
  • จงเปรียบเทียบโฟโตอิเล็กทริกเซนเซอร์ 3 แบบในด้านการติดตั้ง ระยะ และผลของสีวัตถุ
  • โฟโตอิเล็กทริกเซนเซอร์แบบลำแสงผ่านใช้ตรวจชิ้นงานบนสายพาน ต้องการให้เอาต์พุต ON เมื่อมีชิ้นงาน ควรตั้งโหมดใด
  • จงวาดการต่อเซนเซอร์ NPN และ PNP เข้ากับ FX5UJ พร้อมระบุการต่อขั้ว S/S
  • ไฟ LED ของเซนเซอร์ติดเมื่อมีวัตถุ แต่ไฟอินพุต X6 ของ PLC ไม่ติด จงระบุสาเหตุที่เป็นไปได้อย่างน้อย 3 สาเหตุ
🔧 6. เชื่อมโยงกับใบงานปฏิบัติหน่วยเรียนที่ 7

การต่อพร็อกซิมิตีเซนเซอร์แบบเหนี่ยวนำชนิด NPN 3 สายเข้ากับ PLC และการเขียนโปรแกรมตรวจจับวัตถุโลหะ / การต่อโฟโตอิเล็กทริกเซนเซอร์แบบสะท้อนจากวัตถุเข้ากับ PLC การปรับระยะตรวจจับ และการเขียนโปรแกรมตรวจจับวัตถุ
