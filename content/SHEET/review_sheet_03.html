📌 1. สาระสำคัญ

มาตรฐาน IEC 61131-3 กำหนดภาษาโปรแกรม PLC 5 ภาษา ได้แก่ Ladder Diagram (LD), Function Block Diagram (FBD), Structured Text (ST), Instruction List (IL) และ Sequential Function Chart (SFC) ภาษา Ladder เป็นที่นิยมที่สุดเพราะมีรูปแบบคล้ายวงจรรีเลย์ ประกอบด้วยรางไฟซ้ายขวา หน้าสัมผัส NO/NC เป็นเงื่อนไข และคอยล์เป็นผลลัพธ์ การต่อหน้าสัมผัสแบบอนุกรมให้ผลเป็นตรรกะ AND แบบขนานให้ผลเป็นตรรกะ OR คำสั่งพื้นฐานของ PLC Mitsubishi ได้แก่ LD, LDI, AND, ANI, OR, ORI, ANB, ORB, OUT และ END …

🎯 2. จุดประสงค์การเรียน (ทั่วไป)
  • 3.1 อธิบายภาษาโปรแกรม PLC ทั้ง 5 ภาษาตามมาตรฐาน IEC 61131-3 และองค์ประกอบของภาษา Ladder ได้
  • 3.2 แปลงเงื่อนไขการทำงานเป็นสมการตรรกะ ตารางความจริง และโปรแกรม Ladder ได้
  • 3.3 เขียนโปรแกรมด้วยคำสั่งพื้นฐาน LD, LDI, AND, ANI, OR, ORI, ANB, ORB และ OUT ได้
  • 3.4 ออกแบบวงจรอินเตอร์ล็อกและวงจรคงสถานะสำหรับควบคุมเครื่องจักรได้
🧩 3. หัวข้อเนื้อหาในหน่วย
  • 3.1 ภาษาโปรแกรมของพีแอลซีตามมาตรฐาน IEC 61131-3
  • 3.2 โครงสร้างและสัญลักษณ์ของภาษาแลดเดอร์
  • 3.3 ตรรกะพื้นฐานและการแปลงเป็นโปรแกรมแลดเดอร์
  • 3.4 คำสั่งพื้นฐานของพีแอลซี Mitsubishi
  • 3.5 วงจรอินเตอร์ล็อก
  • 3.6 วงจรคงสถานะ
📝 4. บทสรุป

IEC 61131-3 มี 5 ภาษา: LD, FBD, ST, IL, SFC รายวิชานี้ใช้ LD เป็นหลัก Ladder: อนุกรม = AND ขนาน = OR หน้าสัมผัส NC = NOT คอยล์อยู่ขวาสุด หลีกเลี่ยง Double coil คำสั่งพื้นฐาน: LD, LDI, AND, ANI, OR, ORI, ANB, ORB, OUT, END Input Interlock ใช้ NC ของปุ่มอีกตัว · Output Interlock ใช้ NC ของเอาต์พุตอีกตัว Self-holding: Y = (START + Y)·S̅T̅O̅P̅ (หยุดมีความสำคัญกว่า) ปุ่ม STOP ต่อแบบ NC (Fail-safe)

❓ 5. คำถามทบทวน (จากแบบฝึกหัดท้ายหน่วย)
  • จงเปรียบเทียบภาษาโปรแกรม PLC ตามมาตรฐาน IEC 61131-3 ทั้ง 5 ภาษา พร้อมบอกงานที่เหมาะสม
  • เครื่องอัดชิ้นงานต้องทำงาน (Y6) เมื่อกดปุ่มสองมือ X3 และ X4 พร้อมกัน และประตูนิรภัยปิด (X5 = 1) …
  • จงลดรูปสมการ Y = A·B + A·B̅ + A̅·B แล้วเขียนเป็น Ladder
  • หลอดเตือน Y4 ต้องติดเมื่อประตูเปิด (X5 = 0) หรือเมื่อแรงดันลมต่ำ (X6 = 1) ขณะเครื่องทำงาน (Y1 = 1) …
  • จงเขียนรายการคำสั่งของสมการ Y1 = X3·X4 + X5·X6
  • จงเขียนรายการคำสั่งของสมการ Y3 = (X3 + X4)·(X5 + X̅6)
🔧 6. เชื่อมโยงกับใบงานปฏิบัติหน่วยเรียนที่ 3

การเขียนโปรแกรมวงจรอินเตอร์ล็อกด้านอินพุต (Input Interlock) และด้านเอาต์พุต (Output Interlock) / การเขียนโปรแกรมวงจรคงสถานะ (Self-holding) แบบหยุดมีความสำคัญกว่าและแบบเริ่มมีความสำคัญกว่า
