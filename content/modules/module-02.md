## จุดประสงค์การสอน

- **2.1 จำแนกชนิดของ PLC ตามโครงสร้างและขนาด และเลือกชนิดให้เหมาะกับงานได้**
- **2.2 อธิบายหน้าที่ของส่วนประกอบหลักของ PLC และชนิดของหน่วยความจำได้**
- **2.3 อธิบายวงจรอินพุตแบบ Sink/Source และวงจรเอาต์พุตแบบรีเลย์ ทรานซิสเตอร์ และไทรแอกได้**
- **2.4 ต่อวงจรอินพุต/เอาต์พุตของ FX5UJ-24MT/ES และเขียนโปรแกรมทดสอบได้ถูกต้อง**

**จุดประสงค์เชิงพฤติกรรม** เมื่อเรียนจบหน่วยนี้แล้ว ผู้เรียนสามารถ

1. เปรียบเทียบ PLC แบบคอมแพกต์กับแบบโมดูลาร์อย่างน้อย 4 ประเด็นได้ (CLO1)
2. อธิบายหน้าที่ของ CPU หน่วยความจำ หน่วยอินพุต หน่วยเอาต์พุต แหล่งจ่ายไฟ และพอร์ตสื่อสารได้ (CLO1)
3. อ่านความหมายของรหัสรุ่น FX5UJ-24MT/ES และระบุหมายเลขอินพุต/เอาต์พุตแบบฐานแปดได้ถูกต้อง (CLO1)
4. เขียนทิศทางการไหลของกระแสในวงจรอินพุตแบบ Sink และ Source ได้ (CLO1)
5. เลือกชนิดเอาต์พุตให้เหมาะกับโหลดและคำนวณความเหมาะสมของกระแสโหลดได้ (CLO1)
6. ต่อปุ่มกดและหลอดไฟเข้ากับ FX5UJ-24MT/ES และเขียนโปรแกรมทดสอบด้วยหน้าสัมผัส NO/NC ได้ (CLO3)
7. ทำงานร่วมกับสมาชิกในกลุ่มและปฏิบัติตามกฎความปลอดภัยทางไฟฟ้าได้ (CLO4)

## 2.1 ชนิดของพีแอลซี

### 2.1.1 PLC แบบคอมแพกต์ (Compact หรือ Fixed PLC)

PLC แบบคอมแพกต์รวมแหล่งจ่ายไฟ หน่วยประมวลผลกลาง หน่วยความจำ
และอินพุต/เอาต์พุตจำนวนหนึ่งไว้ในตัวเครื่องเดียว จำนวน I/O ถูกกำหนดตามรุ่น เช่น 14, 24,
40 หรือ 60 จุด หากต้องการเพิ่มสามารถต่อโมดูลขยายด้านข้างได้ในจำนวนจำกัด PLC
ชนิดนี้มีขนาดเล็ก ราคาต่ำ ติดตั้งง่าย เหมาะกับเครื่องจักรเดี่ยว เช่น เครื่องบรรจุ เครื่องตัด

FX5U), Siemens S7-1200 และ Omron CP1E

### 2.1.2 PLC แบบโมดูลาร์ (Modular PLC)

PLC แบบโมดูลาร์ประกอบด้วยโมดูลแยก ได้แก่ โมดูลแหล่งจ่ายไฟ โมดูล CPU โมดูลอินพุต
โมดูลเอาต์พุต และโมดูลพิเศษ เช่น แอนะล็อก ควบคุมตำแหน่ง และสื่อสาร ติดตั้งบนแร็กหรือเบส
(Base unit) ผู้ออกแบบเลือกจำนวนและชนิดโมดูลได้ตามขนาดงาน
ขยายระบบได้มากและเปลี่ยนโมดูลที่เสียได้โดยไม่ต้องเปลี่ยนทั้งระบบ
เหมาะกับสายการผลิตขนาดใหญ่ เช่น MELSEC iQ-R, Siemens S7-1500 และ
Allen-Bradley ControlLogix

### 2.1.3 การจำแนกตามขนาดและการเลือกใช้

นอกจากจำแนกตามโครงสร้าง PLC ยังจำแนกตามจำนวน I/O ได้เป็น PLC ขนาดเล็ก
(ไม่เกินประมาณ 128 จุด) ขนาดกลาง (ประมาณ 128–512 จุด) และขนาดใหญ่ (มากกว่า 512
จุด) การเลือก PLC ให้พิจารณาจำนวนและชนิด I/O ที่ต้องใช้พร้อมสำรองไว้ประมาณ 20%
ชนิดเอาต์พุตที่เหมาะกับโหลด ความเร็วในการประมวลผล ฟังก์ชันพิเศษ เช่น
การนับความเร็วสูงและการควบคุมตำแหน่ง ช่องทางสื่อสาร สภาพแวดล้อมการติดตั้ง
การสนับสนุนจากผู้แทนจำหน่าย และความคุ้นเคยของช่างซ่อมบำรุงในโรงงาน

ตารางที่ 2.2 เปรียบเทียบ PLC แบบคอมแพกต์กับแบบโมดูลาร์

| **ประเด็น**  | **แบบคอมแพกต์**           | **แบบโมดูลาร์**           |
|-------------|--------------------------|-------------------------|
| โครงสร้าง    | รวมทุกส่วนในตัวเดียว         | แยกโมดูลติดตั้งบนแร็ก/เบส    |
| จำนวน I/O   | คงที่ตามรุ่น ขยายได้จำกัด      | เลือกและขยายได้มาก        |
| ขนาดและราคา | เล็ก ราคาต่ำ               | ใหญ่ ราคาสูงกว่า           |
| การซ่อมบำรุง  | เปลี่ยนทั้งตัวเมื่อเสีย          | เปลี่ยนเฉพาะโมดูลที่เสีย      |
| ฟังก์ชันพิเศษ   | มีในตัวบางส่วน              | เพิ่มโมดูลพิเศษได้หลากหลาย   |
| งานที่เหมาะ   | เครื่องจักรเดี่ยวขนาดเล็ก–กลาง | สายการผลิตและระบบขนาดใหญ่ |

## 2.2 ส่วนประกอบหลักของพีแอลซี

PLC ทุกชนิดประกอบด้วยส่วนหลักที่ทำงานร่วมกัน ได้แก่ แหล่งจ่ายไฟ หน่วยประมวลผลกลาง
หน่วยความจำ หน่วยอินพุต หน่วยเอาต์พุต และพอร์ตสื่อสาร ส่วนต่าง ๆ
เชื่อมต่อกันด้วยบัสข้อมูลภายใน
อุปกรณ์เขียนโปรแกรมเชื่อมต่อผ่านพอร์ตสื่อสารเพื่อดาวน์โหลดโปรแกรมและมอนิเตอร์การทำงาน

![ภาพที่ 2.4 ส่วนประกอบหลักของ PLC และการเชื่อมต่อภายใน](/images/book/m23_0017.png)

### 2.2.1 แหล่งจ่ายไฟ (Power supply)

แหล่งจ่ายไฟแปลงไฟฟ้ากระแสสลับ 100–240 VAC
เป็นไฟฟ้ากระแสตรงแรงดันต่ำเพื่อเลี้ยงวงจรภายในของ PLC PLC แบบคอมแพกต์หลายรุ่น รวมถึง
FX5UJ มีแหล่งจ่าย 24 VDC สำหรับเซนเซอร์ภายนอก (Service power supply)
ในปริมาณกระแสจำกัด หากใช้เซนเซอร์และโหลดจำนวนมากควรใช้แหล่งจ่าย 24 VDC
ภายนอกแยกต่างหาก

### 2.2.2 หน่วยประมวลผลกลางและหน่วยความจำ

หน่วยประมวลผลกลาง (Central Processing Unit: CPU) อ่านภาพอินพุต
ประมวลผลคำสั่งในโปรแกรม จัดการไทเมอร์ เคาน์เตอร์ และการสื่อสาร
แล้วเขียนผลลงภาพเอาต์พุต หน่วยความจำของ PLC แบ่งเป็น 2 ส่วน คือ หน่วยความจำโปรแกรม
(Program memory) เก็บโปรแกรมของผู้ใช้และพารามิเตอร์ในหน่วยความจำแบบไม่ลบเลือน เช่น
Flash ROM และหน่วยความจำข้อมูล (Data memory) เก็บสถานะของอุปกรณ์ภายใน เช่น X,
Y, M, T, C และ D ซึ่งส่วนใหญ่เป็น RAM ค่าจะหายเมื่อปิดไฟ ยกเว้นพื้นที่ที่กำหนดเป็นแบบคงค่า
(Latch)

ตารางที่ 2.3 อุปกรณ์ (Device) ในหน่วยความจำข้อมูลของ PLC ตระกูล FX5

|-----------|--------------------------------|--------------------------------|------------------|
| X         | อินพุต (Input)                   | สถานะจากขั้วอินพุตจริง              | ฐานแปด           |

| L         | รีเลย์คงค่า (Latch relay)         | บิตที่คงค่าเมื่อไฟดับ                 | ฐานสิบ            |
| SM        | รีเลย์พิเศษ (Special relay)       | บิตที่ระบบกำหนดหน้าที่               | ฐานสิบ            |
| T         | ไทเมอร์ (Timer)                 | หน่วงเวลา หน่วย 100 ms (ค่าเริ่มต้น) | ฐานสิบ            |

| SD        | รีจิสเตอร์พิเศษ (Special register) | ข้อมูลระบบ เช่น ตำแหน่งปัจจุบันของแกน | ฐานสิบ            |

### 2.2.3 หน่วยอินพุตและหน่วยเอาต์พุต

หน่วยอินพุต (Input unit) รับสัญญาณจากอุปกรณ์ภายนอก เช่น ปุ่มกด ลิมิตสวิตช์ และเซนเซอร์
แปลงเป็นระดับสัญญาณภายในผ่านวงจรกรองสัญญาณรบกวนและออปโตคัปเปลอร์ซึ่งแยกทางไฟฟ้าระหว่างวงจรภายนอกกับ
CPU หน่วยเอาต์พุต (Output unit) รับผลจาก CPU แล้วขยายเป็นสัญญาณกำลังเพื่อสั่งโหลด
เช่น หลอดไฟ รีเลย์ คอนแทคเตอร์ และโซลินอยด์วาล์ว แต่ละจุดมีไฟ LED แสดงสถานะ
ช่วยในการตรวจสอบความผิดปกติ

### 2.2.4 พอร์ตสื่อสารและส่วนประกอบภายนอกของ FX5UJ

พอร์ตสื่อสารใช้เชื่อมต่อคอมพิวเตอร์ หน้าจอ HMI และอุปกรณ์อื่น PLC FX5UJ
มีพอร์ตอีเทอร์เน็ตในตัวสำหรับเขียนโปรแกรมและสื่อสาร และติดตั้งบอร์ดสื่อสารเพิ่ม เช่น RS-485
ได้ ด้านหน้าตัว CPU มีไฟ LED แสดงสถานะ ได้แก่ PWR (มีไฟเลี้ยง) ERR (เกิดข้อผิดพลาด)
P.RUN (โหมด RUN) และ BAT/CARD สวิตช์ RUN/STOP/RESET ใช้เปลี่ยนโหมดการทำงาน
และมีช่องเสียบการ์ดหน่วยความจำ SD สำหรับสำรองโปรแกรม

## 2.4 วงจรอินพุตของพีแอลซี

### 2.4.1 อินพุตแบบ Sink

FX5UJ ใช้ขั้วร่วม S/S กำหนดลักษณะของวงจรอินพุต การต่อแบบ Sink ทำโดยต่อ +24 VDC
เข้าขั้ว S/S และต่อ 0 VDC ที่ขาด้านหนึ่งของสวิตช์ ขาอีกด้านต่อเข้าขั้ว X เมื่อสวิตช์ปิด
กระแสไหลจาก +24 VDC เข้าขั้ว S/S ผ่านไดโอดเปล่งแสงของออปโตคัปเปลอร์ ออกทางขั้ว X
ผ่านสวิตช์ลงสู่ 0 VDC กล่าวคือกระแส "ไหลออก" จากขั้วอินพุต
ใช้กับสวิตช์ทั่วไปและเซนเซอร์ชนิด NPN ซึ่งเป็นการต่อที่ใช้ในชุดฝึกของรายวิชา

![ภาพที่ 2.8 การต่อวงจรอินพุตแบบ Sink และแบบ Source ของ FX5UJ พร้อมทิศทางกระแส](/images/book/m23_0021.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Mitsubishi Electric Corporation (2023))

### 2.4.2 อินพุตแบบ Source

การต่อแบบ Source ทำโดยต่อ 0 VDC เข้าขั้ว S/S และต่อ +24 VDC ที่ขาด้านหนึ่งของสวิตช์
เมื่อสวิตช์ปิด กระแส "ไหลเข้า" ขั้ว X ผ่านออปโตคัปเปลอร์ไปยังขั้ว S/S ใช้กับเซนเซอร์ชนิด
PNP ซึ่งนิยมในยุโรป ข้อควรระวังคืออินพุตทุกจุดที่ใช้ขั้ว S/S ร่วมกันต้องต่อแบบเดียวกัน
จะผสมเซนเซอร์ NPN และ PNP ในกลุ่มเดียวกันไม่ได้

|------------------------|---------------|-----------------------|---------------------|
| ปุ่มกด/ลิมิตสวิตช์ (หน้าสัมผัส) | ไม่มีขั้ว         | +24 VDC หรือ 0 VDC ก็ได้ | Sink หรือ Source     |

### 2.4.3 เวลาตอบสนองและการกรองสัญญาณ

วงจรอินพุตมีตัวกรองสัญญาณรบกวน (Input filter) ซึ่งตั้งค่าได้ในพารามิเตอร์ ค่าเริ่มต้นของ
FX5 ประมาณ 10 ms หมายความว่าสัญญาณที่สั้นกว่าค่านี้จะถูกตัดทิ้ง
ช่วยลดผลของการกระเด้งของหน้าสัมผัส (Contact bounce) แต่ถ้าต้องการรับสัญญาณเร็ว เช่น
พัลส์จากเอนโคเดอร์ ต้องลดค่ากรองหรือใช้อินพุตความเร็วสูง

## 2.5 วงจรเอาต์พุตของพีแอลซี

### 2.5.1 เอาต์พุตแบบรีเลย์ (Relay output)

เอาต์พุตแบบรีเลย์ใช้หน้าสัมผัสของรีเลย์ขนาดเล็กภายใน PLC ต่อวงจรโหลด
ใช้ได้กับโหลดทั้งไฟฟ้ากระแสตรงและกระแสสลับ ทนกระแสได้ประมาณ 2 A ต่อจุด แต่ตอบสนองช้า
(ประมาณ 10 ms) และหน้าสัมผัสมีอายุการใช้งานจำกัดตามจำนวนครั้งที่ตัดต่อ
จึงไม่เหมาะกับโหลดที่เปิด–ปิดถี่และสัญญาณพัลส์

### 2.5.2 เอาต์พุตแบบทรานซิสเตอร์ (Transistor output)

เอาต์พุตแบบทรานซิสเตอร์ใช้ทรานซิสเตอร์เป็นสวิตช์อิเล็กทรอนิกส์
ใช้ได้กับโหลดไฟฟ้ากระแสตรงเท่านั้น ตอบสนองเร็ว (ระดับไมโครวินาที) ไม่มีการสึกหรอ
และส่งพัลส์ความถี่สูงเพื่อควบคุมสเต็ปปิงมอเตอร์หรือเซอร์โวมอเตอร์ได้ แต่ทนกระแสได้น้อยกว่า
(ประมาณ 0.3–0.5 A ต่อจุด) FX5UJ-24MT/ES เป็นเอาต์พุตแบบ Sink โหลดต่อระหว่าง +24
VDC กับขั้ว Y และขั้ว COM ต่อ 0 VDC เมื่อเอาต์พุต ON ทรานซิสเตอร์ดึงขั้ว Y ลงสู่ COM
ทำให้โหลดทำงาน หากโหลดเป็นขดลวด เช่น รีเลย์หรือโซลินอยด์วาล์ว
ควรต่อไดโอดคร่อมขดลวดเพื่อดูดซับแรงดันเหนี่ยวนำย้อนกลับ

![ภาพที่ 2.10 วงจรเอาต์พุตแบบรีเลย์ ทรานซิสเตอร์ (Sink) และไทรแอก](/images/book/m23_0023.png)

(ที่มา: ผู้จัดทำ อ้างอิงแนวคิดจาก Bolton (2015))

### 2.5.3 เอาต์พุตแบบไทรแอก (Triac output)

เอาต์พุตแบบไทรแอกใช้ไทรแอกเป็นสวิตช์อิเล็กทรอนิกส์สำหรับไฟฟ้ากระแสสลับ
ตอบสนองเร็วกว่ารีเลย์และไม่มีหน้าสัมผัสสึกหรอ เหมาะกับโหลด AC ที่เปิด–ปิดบ่อย เช่น
คอยล์คอนแทคเตอร์ 220 VAC แต่มีกระแสรั่วขณะ OFF เล็กน้อย
ซึ่งอาจทำให้โหลดขนาดเล็กมากไม่ดับสนิท

ตารางที่ 2.7 เปรียบเทียบเอาต์พุตของ PLC 3 ชนิด

| **คุณสมบัติ**       | **รีเลย์**                      | **ทรานซิสเตอร์**             | **ไทรแอก**             |
|------------------|-------------------------------|----------------------------|------------------------|
| ชนิดโหลด          | AC และ DC                     | DC เท่านั้น                   | AC เท่านั้น               |
| กระแสต่อจุด (ทั่วไป) | ประมาณ 2 A                    | ประมาณ 0.3–0.5 A           | ประมาณ 0.3–0.5 A       |
| ความเร็วตอบสนอง   | ช้า (ประมาณ 10 ms)             | เร็วมาก (µs)                | เร็ว (ประมาณ 1 ms)      |
| อายุการใช้งาน      | จำกัดด้วยหน้าสัมผัส                | ยาว ไม่มีการสึกหรอ            | ยาว ไม่มีการสึกหรอ        |
| ส่งพัลส์ความถี่สูง     | ไม่ได้                          | ได้                         | ไม่ได้                   |
| ตัวอย่างโหลด       | มอเตอร์ผ่านคอนแทคเตอร์ หลอดไฟ AC | โซลินอยด์ 24 V ไดรเวอร์สเต็ปปิง | คอยล์คอนแทคเตอร์ 220 VAC |

### 2.5.4 การคำนวณกระแสโหลดและการขับโหลดขนาดใหญ่

ก่อนต่อโหลดต้องคำนวณกระแสโหลดจากกำลังและแรงดัน I = P/V
และตรวจว่าไม่เกินพิกัดต่อจุดและพิกัดรวมต่อกลุ่ม COM ตัวอย่าง หลอดไฟ 24 V 2 W มีกระแส
2/24 ≈ 0.083 A ใช้ได้กับเอาต์พุตทรานซิสเตอร์ ส่วนมอเตอร์กระแสตรง 24 V
ที่กินกระแสเริ่มหมุน 2 A เกินพิกัด ต้องขับผ่านรีเลย์หรือคอนแทคเตอร์ภายนอก
ซึ่งเป็นวิธีที่ชุดฝึกใช้ขับมอเตอร์ไฟฟ้ากระแสตรงผ่านรีเลย์ R1 และ R2

## 2.6 การต่อวงจรอินพุต/เอาต์พุตของชุดฝึก

### 2.6.1 ขั้นตอนการต่อวงจรอย่างปลอดภัย

การต่อวงจรของชุดฝึกมีขั้นตอนดังนี้ (1) ปลดเบรกเกอร์ให้ชุดฝึกไม่มีไฟ (2) ต่อ +24 VDC
เข้าขั้ว S/S สำหรับอินพุตแบบ Sink (3) ต่อสายจากอุปกรณ์อินพุตเข้าขั้ว X
ตามตารางกำหนดอินพุต/เอาต์พุต และต่อขาร่วมของสวิตช์เข้า 0 VDC (4) ต่อขั้ว COM
ของเอาต์พุตเข้า 0 VDC และต่อโหลดระหว่าง +24 VDC กับขั้ว Y (5)
ตรวจสอบการต่อด้วยสายตาและมัลติมิเตอร์ย่านความต่อเนื่อง (6) ให้ผู้สอนตรวจก่อนจ่ายไฟ และ
(7) จ่ายไฟแล้วตรวจไฟ LED ที่ขั้วอินพุตขณะกดสวิตช์ก่อนเขียนโปรแกรม

### 2.6.2 หน้าสัมผัส NO และ NC ในโปรแกรมกับอุปกรณ์จริง

ผู้เรียนต้องแยกให้ออกระหว่างหน้าสัมผัสของอุปกรณ์จริงกับหน้าสัมผัสในโปรแกรม ปุ่มกดชนิด NO
ทำให้บิต X เป็น ON เมื่อกด ส่วนปุ่มกดชนิด NC (เช่น ปุ่ม STOP หรือสวิตช์หยุดฉุกเฉิน) ทำให้บิต
X เป็น ON ตลอดเวลาที่ไม่ได้กด ในโปรแกรม หน้าสัมผัส NO (LD) ส่งผ่านเงื่อนไขเมื่อบิตเป็น
ON และหน้าสัมผัส NC (LDI) ส่งผ่านเมื่อบิตเป็น OFF ดังนั้นปุ่ม STOP ที่ต่อแบบ NC
จึงใช้หน้าสัมผัส NO ในโปรแกรม เพื่อให้เครื่องหยุดเองเมื่อสายขาด (Fail-safe)

ตารางที่ 2.8 ผลของชนิดหน้าสัมผัสจริงกับหน้าสัมผัสในโปรแกรม

| **อุปกรณ์จริง** | **สถานะอุปกรณ์** | **บิต X** | **หน้าสัมผัส NO ในโปรแกรม** | **หน้าสัมผัส NC ในโปรแกรม** |
|--------------|----------------|----------|--------------------------|--------------------------|
| ปุ่มกด NO      | ไม่กด           | OFF      | เปิด (ไม่ผ่าน)              | ปิด (ผ่าน)                 |
| ปุ่มกด NO      | กด             | ON       | ปิด (ผ่าน)                 | เปิด (ไม่ผ่าน)              |
| ปุ่มกด NC      | ไม่กด           | ON       | ปิด (ผ่าน)                 | เปิด (ไม่ผ่าน)              |
| ปุ่มกด NC      | กด             | OFF      | เปิด (ไม่ผ่าน)              | ปิด (ผ่าน)                 |

ขยายและซ่อมบำรุงง่าย

ฐานแปด

\- Sink input: S/S ต่อ +24 V ใช้กับสวิตช์และ NPN · Source input: S/S ต่อ 0 V
ใช้กับ PNP

\- เอาต์พุต: รีเลย์ (AC/DC, 2 A, ช้า) ทรานซิสเตอร์ (DC, เร็ว, พัลส์) ไทรแอก (AC,
เร็ว)

## บทสรุป

PLC จำแนกตามโครงสร้างได้เป็นแบบคอมแพกต์ (Compact) ซึ่งรวม CPU แหล่งจ่ายไฟ
และอินพุต/เอาต์พุตไว้ในตัวเดียว และแบบโมดูลาร์ (Modular)
ซึ่งประกอบโมดูลแยกบนแร็กหรือเบส ส่วนประกอบหลักของ PLC ได้แก่ แหล่งจ่ายไฟ
หน่วยประมวลผลกลาง หน่วยความจำ หน่วยอินพุต หน่วยเอาต์พุต และพอร์ตสื่อสาร
หน่วยอินพุตแปลงสัญญาณจากสวิตช์และเซนเซอร์ให้เป็นระดับสัญญาณภายในโดยแยกทางไฟฟ้าด้วยออปโตคัปเปลอร์
ต่อได้ทั้งแบบ Sink และ Source ส่วนหน่วยเอาต์พุตมีทั้งแบบรีเลย์ ทรานซิสเตอร์ และไทรแอก
ซึ่งเหมาะกับโหลดต่างกัน PLC Mitsubishi FX5UJ-24MT/ES ที่ใช้ในรายวิชามีอินพุต 14 จุด
(X0–X7, X10–X15) และเอาต์พุตทรานซิสเตอร์แบบ Sink 10 จุด (Y0–Y7, Y10–Y11)
นับหมายเลขเป็นเลขฐานแปด ผู้เรียนต้องอ่านรหัสรุ่น เลือกชนิดเอาต์พุต
และต่อวงจรอินพุต/เอาต์พุตได้ถูกต้องและปลอดภัย

FX5UJ-24MT/ES: ซีรีส์ FX5UJ, I/O 24 จุด, หน่วยหลัก, เอาต์พุตทรานซิสเตอร์, ไฟ AC เอาต์พุต Sink

FX5UJ-40MR/ES: I/O 40 จุด เอาต์พุตรีเลย์ ไฟ AC

</details>

**5. จงเขียนหมายเลขอินพุตทั้งหมดของ FX5UJ-24MT/ES และอธิบายเหตุผลที่ไม่มี X8, X9**

<details><summary>เฉลย</summary>

X0, X1, X2, X3, X4, X5, X6, X7, X10, X11, X12, X13, X14, X15

หมายเลข X/Y นับเป็นเลขฐานแปด ซึ่งใช้เฉพาะเลข 0–7

</details>

**6. จงวาดวงจรอินพุตแบบ Sink ของปุ่มกดที่ต่อกับ X3 และอธิบายทิศทางการไหลของกระแส**

<details><summary>เฉลย</summary>

+24 VDC → ขั้ว S/S → ไดโอดของออปโตคัปเปลอร์ → ขั้ว X3 → ปุ่มกด → 0 VDC

กระแสไหลออกจากขั้ว X จึงเรียกว่า Sink input

</details>

**7. เซนเซอร์ PNP และเซนเซอร์ NPN ต้องต่อกับอินพุตแบบใด และนำมาต่อในกลุ่ม S/S เดียวกันได้หรือไม่**

<details><summary>เฉลย</summary>

PNP ต่อแบบ Source (S/S ต่อ 0 V)

NPN ต่อแบบ Sink (S/S ต่อ +24 V)

ต่อในกลุ่มเดียวกันไม่ได้ เพราะขั้ว S/S ร่วมกันต้องต่อแรงดันเดียว

</details>

**8. จงเลือกชนิดเอาต์พุตที่เหมาะสมสำหรับโหลดต่อไปนี้: (ก) ไดรเวอร์สเต็ปปิงมอเตอร์ (ข) คอยล์คอนแทคเตอร์ 220 VAC ที่ตัดต่อวันละ 20 ครั้ง (ค) โซลินอยด์วาล์ว 24 VDC ที่ทำงานทุก 1 วินาที**

<details><summary>เฉลย</summary>

(ก) ทรานซิสเตอร์ เพราะต้องส่งพัลส์ความถี่สูง

(ข) รีเลย์หรือไทรแอก ใช้ไฟ AC ตัดต่อไม่ถี่

(ค) ทรานซิสเตอร์ ไม่สึกหรอเมื่อทำงานถี่ และต่อไดโอดคร่อมขดลวด

</details>

**9. หลอดไฟ 24 VDC ขนาด 3 W จำนวน 4 ดวงต่อกับเอาต์พุตทรานซิสเตอร์คนละจุด พิกัด 0.5 A ต่อจุด และ 0.8 A ต่อกลุ่ม COM 4 จุด จงตรวจว่าใช้ได้หรือไม่**

<details><summary>เฉลย</summary>

กระแสต่อดวง = 3/24 = 0.125 A ไม่เกิน 0.5 A

กระแสรวมกลุ่ม = 4 × 0.125 = 0.5 A ไม่เกิน 0.8 A

ใช้ได้

</details>

**10. ปุ่ม STOP ต่อเป็นหน้าสัมผัส NC เข้าที่ X4 จงอธิบายว่าในโปรแกรมควรใช้หน้าสัมผัสแบบใดของ X4 และมีข้อดีอย่างไร**

<details><summary>เฉลย</summary>

ปกติ X4 = ON จึงใช้หน้าสัมผัส NO ของ X4 อนุกรมในวงจร

เมื่อกด STOP หรือสายขาด X4 = OFF วงจรถูกตัด เครื่องหยุดเอง (Fail-safe)

</details>
