## จุดประสงค์การสอน

- **4.1 อธิบายหน้าที่และความแตกต่างของรีเลย์ภายใน M รีเลย์คงค่า L และรีเลย์พิเศษ SM ได้**
- **4.2 เขียนโปรแกรมควบคุมด้วยคำสั่ง SET, RST, ZRST, PLS และ PLF ได้**
- **4.3 ใช้รีเลย์พิเศษสร้างสัญญาณกะพริบ สัญญาณเริ่มต้น และวงจรแจ้งเตือนได้**
- **4.4 ออกแบบโปรแกรมแจ้งเตือนเหตุฉุกเฉินและการเลือกโหมดการทำงานที่ปลอดภัยได้**

**จุดประสงค์เชิงพฤติกรรม** เมื่อเรียนจบหน่วยนี้แล้ว ผู้เรียนสามารถ

1. อธิบายความแตกต่างระหว่าง M, L, SM กับ X และ Y ได้อย่างน้อย 3 ประเด็น (CLO1)
2. ใช้รีเลย์ภายในเป็นตัวกลางเก็บสถานะ RUN และสั่งเอาต์พุตหลายจุดร่วมกับสวิตช์ทางเลือกได้ (CLO2)
3. เลือกใช้รีเลย์พิเศษ SM400, SM402 และ SM412 ได้ตรงตามหน้าที่ (CLO2)
4. เขียนโปรแกรมด้วย SET/RST และอธิบายผลเมื่อเงื่อนไขทั้งสองเป็นจริงพร้อมกันได้ (CLO2)
5. ใช้คำสั่ง PLS/PLF สร้างวงจร Toggle (กดครั้งที่หนึ่งติด กดครั้งที่สองดับ) ได้ (CLO2)
6. ต่อสวิตช์หยุดฉุกเฉินแบบ NC และเขียนโปรแกรมแจ้งเตือนด้วยหลอดกะพริบและบัซเซอร์กับชุดฝึกได้ (CLO3)
7. ทำงานร่วมกับสมาชิกในกลุ่มอย่างรับผิดชอบและปฏิบัติตามขั้นตอนความปลอดภัยได้ (CLO4)

## 4.1 อุปกรณ์บิตภายในหน่วยความจำของพีแอลซี

### 4.1.1 ภาพรวมของอุปกรณ์บิต

PLC เก็บข้อมูลในหน่วยความจำเป็นอุปกรณ์ (Device) ซึ่งแบ่งเป็นอุปกรณ์บิต (Bit device)
ที่มีค่า ON/OFF และอุปกรณ์เวิร์ด (Word device) ที่เก็บตัวเลข อุปกรณ์บิต X และ Y
เชื่อมกับขั้วต่อจริง ส่วนอุปกรณ์บิต M, L และ SM อยู่ภายในหน่วยความจำเท่านั้น
ใช้เป็นเงื่อนไขหรือผลลัพธ์ในโปรแกรมได้เหมือนรีเลย์จริงแต่ไม่มีชิ้นส่วนสึกหรอ
และมีหน้าสัมผัสไม่จำกัดจำนวน

ตารางที่ 4.2 อุปกรณ์บิตของ PLC FX5 และการใช้งาน

|-----------|-----------|---------------|------------------|---------------|---------------------------|
| X         | อินพุต      | อ่านใหม่        | ได้               | ไม่ได้          | ปุ่มกด เซนเซอร์              |
| Y         | เอาต์พุต    | OFF           | ได้               | ได้            | หลอดไฟ โซลินอยด์            |
| M         | รีเลย์ภายใน | OFF           | ได้               | ได้            | สถานะ RUN โหมด ขั้นการทำงาน |

### 4.1.2 รีเลย์ภายใน (Internal relay: M)

รีเลย์ภายในใช้เก็บสถานะกลางของโปรแกรม เช่น สถานะเครื่องพร้อมทำงาน สถานะ RUN
โหมดการทำงาน หรือขั้นตอนของงานลำดับ ข้อดีของการใช้ M เป็นตัวกลางคือ
แยกตรรกะการตัดสินใจออกจากเอาต์พุตจริง แก้ไขเงื่อนไขได้ที่จุดเดียว
และนำสถานะไปใช้ได้หลายแถว ตัวอย่าง เครื่องจักรมีหลอดไฟ 3 ดวงที่ต้องแสดงผลตามสถานะ
RUN และโหมด ผู้เขียนโปรแกรมเก็บสถานะ RUN แบบคงสถานะไว้ใน M10 แล้วใช้หน้าสัมผัส M10
ร่วมกับสวิตช์ทางเลือกสั่งหลอดแต่ละดวง

### 4.1.3 รีเลย์คงค่า (Latch relay: L)

รีเลย์คงค่ามีการทำงานเหมือนรีเลย์ภายใน แต่ค่าถูกเก็บในหน่วยความจำสำรอง
จึงคงสถานะเดิมเมื่อไฟฟ้าดับแล้วกลับมา ใช้จำข้อมูลที่ต้องรักษาไว้ เช่น
ขั้นตอนการผลิตล่าสุดหรือโหมดที่ผู้ใช้เลือก ข้อควรระวังคือ หากใช้ L สั่งเอาต์พุตโดยตรง
เครื่องจักรอาจเริ่มทำงานเองทันทีที่ไฟกลับมา ซึ่งเป็นอันตราย จึงควรใช้ L
เก็บข้อมูลแล้วให้ผู้ปฏิบัติงานยืนยันการเริ่มทำงานใหม่ด้วยปุ่ม START เสมอ

### 4.1.4 สวิตช์ทางเลือกและการเลือกโหมดการทำงาน

เครื่องจักรอัตโนมัติส่วนใหญ่มีโหมด MANUAL สำหรับปรับตั้งและบำรุงรักษา และโหมด AUTO
สำหรับผลิตจริง สวิตช์ทางเลือก (Selector switch) 3 ตำแหน่งของชุดฝึกส่งสัญญาณเข้า X1
เมื่อบิดขวาและ X2 เมื่อบิดซ้าย ตำแหน่งกลางไม่มีสัญญาณ
โปรแกรมควรเก็บโหมดไว้ในรีเลย์ภายใน เช่น M20 = AUTO และ M21 = MANUAL
พร้อมอินเตอร์ล็อกไม่ให้ทั้งสองโหมดทำงานพร้อมกัน
และเมื่อเปลี่ยนโหมดขณะเครื่องทำงานควรหยุดเครื่องก่อน

## 4.2 รีเลย์พิเศษ (Special relay: SM)

### 4.2.1 รีเลย์พิเศษที่ใช้บ่อย

รีเลย์พิเศษเป็นบิตที่ระบบปฏิบัติการของ CPU กำหนดหน้าที่ไว้แล้ว บางตัวแสดงสถานะของ CPU
บางตัวให้สัญญาณนาฬิกา และบางตัวเป็นแฟล็กของคำสั่งพิเศษ เช่น คำสั่งควบคุมตำแหน่ง
ผู้เขียนโปรแกรมใช้หน้าสัมผัสของรีเลย์พิเศษได้ทันทีโดยไม่ต้องเขียนโปรแกรมสร้างสัญญาณเอง PLC
ตระกูล FX5 ยังรองรับรีเลย์พิเศษแบบ FX3 (SM8000 ขึ้นไป)
เพื่อความเข้ากันได้กับโปรแกรมเดิม

## 4.3 คำสั่ง SET, RST และ ZRST

### 4.3.1 หลักการทำงานของ SET และ RST

คำสั่ง SET ตั้งบิตปลายทางให้เป็น ON เมื่อเงื่อนไขของแถวเป็นจริง และบิตยังคงเป็น ON
แม้เงื่อนไขหายไป จนกว่าคำสั่ง RST จะล้างบิตนั้นเป็น OFF การใช้ SET/RST
จึงให้ผลเหมือนวงจรคงสถานะ แต่เขียนเงื่อนไขเริ่มและเงื่อนไขหยุดแยกแถวกัน
ทำให้เขียนโปรแกรมที่มีเงื่อนไขหยุดหลายกรณีได้สะดวก เช่น หยุดเมื่อกด STOP
หรือเมื่อเกิดเหตุฉุกเฉินหรือเมื่อนับครบจำนวน คำสั่ง RST
ยังใช้ล้างค่าปัจจุบันของไทเมอร์และเคาน์เตอร์ได้ ส่วนคำสั่ง ZRST ใช้ล้างอุปกรณ์เป็นช่วง เช่น
ZRST M100 M108 ล้างรีเลย์ภายใน M100 ถึง M108 พร้อมกัน

![ภาพที่ 4.4 โปรแกรม SET/RST และผังเวลาการทำงาน](/images/book/m23_0048.png)

(ที่มา: ผู้จัดทำ ดัดแปลงจาก Konlatee Design Mechanical LP (2567))

### 4.3.2 ลำดับแถวเมื่อ SET และ RST ทำงานพร้อมกัน

เนื่องจาก PLC ประมวลผลจากบนลงล่าง หากเงื่อนไขของ SET และ RST
เป็นจริงพร้อมกันในรอบสแกนเดียว คำสั่งที่อยู่หลังสุดจะกำหนดสถานะที่ส่งออก ดังนั้นการวางแถว
RST ไว้หลังแถว SET ทำให้การหยุดมีความสำคัญกว่าซึ่งปลอดภัย
ข้อดีนี้ทำให้ผู้ออกแบบสามารถควบคุมลำดับความสำคัญได้ แต่ต้องตรวจสอบลำดับแถวทุกครั้ง
โดยเฉพาะเมื่อแก้ไขโปรแกรมภายหลัง

ตารางที่ 4.4 เปรียบเทียบวงจรคงสถานะด้วย OUT กับการใช้ SET/RST

| **ประเด็น**      | **วงจรคงสถานะด้วย OUT**        | **SET/RST**             |
|-----------------|-------------------------------|-------------------------|
| จำนวนแถว        | 1 แถว                         | อย่างน้อย 2 แถว           |
| การเพิ่มเงื่อนไขหยุด | เพิ่มหน้าสัมผัสอนุกรม               | เพิ่มกิ่งขนานในแถว RST      |
| ลำดับความสำคัญ    | กำหนดด้วยตำแหน่งหน้าสัมผัส         | กำหนดด้วยลำดับแถว         |
| ใช้กับรีเลย์คงค่า L  | ค่าไม่คงเพราะ OUT ประมวลผลทุกรอบ | คงค่าได้                  |
| ความเสี่ยง        | ต่ำ ตรวจสอบง่าย                 | ลืมแถว RST ทำให้เอาต์พุตค้าง |

### 4.3.3 ข้อควรระวังในการใช้ SET/RST

การใช้ SET/RST ต้องระวัง (1) ทุก SET ต้องมีเงื่อนไข RST ที่ครอบคลุมเหตุหยุดทุกกรณี
รวมถึงเหตุฉุกเฉิน (2) ไม่ควรใช้ OUT กับอุปกรณ์เดียวกันที่ถูก SET/RST เพราะ OUT
จะเขียนทับทุกรอบสแกน (3) ควรใช้ SM402 ล้างสถานะที่ไม่ต้องการเมื่อเริ่ม RUN และ (4)
เมื่อหยุด PLC สถานะของ Y จะดับ แต่สถานะของ L ที่ถูก SET จะคงอยู่
ต้องออกแบบให้ปลอดภัยเมื่อเริ่มใหม่

## 4.4 คำสั่งตรวจจับขอบสัญญาณ PLS และ PLF

### 4.4.1 หลักการของพัลส์ขอบขาขึ้นและขอบขาลง

คำสั่ง PLS (Pulse) ทำให้บิตปลายทางเป็น ON เพียงหนึ่งรอบสแกนเมื่อเงื่อนไขเปลี่ยนจาก OFF
เป็น ON (ขอบขาขึ้น) และคำสั่ง PLF (Pulse falling) ทำให้บิตเป็น ON
หนึ่งรอบสแกนเมื่อเงื่อนไขเปลี่ยนจาก ON เป็น OFF (ขอบขาลง)
ใช้ในงานที่ต้องการให้เหตุการณ์เกิดขึ้นครั้งเดียวต่อการกดหนึ่งครั้ง เช่น
สั่งกระบอกสูบยืดหนึ่งครั้งต่อชิ้นงาน หรือเพิ่มค่าตัวนับ นอกจากนี้ยังมีหน้าสัมผัสแบบตรวจขอบ (LDP,
LDF) ที่ให้ผลคล้ายกัน

### 4.4.2 วงจรกดติด–กดดับ (Toggle)

วงจร Toggle ทำให้ปุ่มเดียวสั่งเปิดและปิดอุปกรณ์สลับกัน เช่น กดครั้งแรกหลอดติด
กดครั้งที่สองหลอดดับ หากไม่ใช้พัลส์
ขณะกดค้างหลายรอบสแกนเอาต์พุตจะสลับไปมาจนคาดเดาผลไม่ได้ วิธีเขียนคือสร้างพัลส์ M0 ด้วย
LD X3, PLS M0 แล้วเขียนแถวของ Y1 ตามสมการ Y1 = M0·Y̅1 + M̅0·Y1 ซึ่งเป็นตรรกะ
XOR ระหว่างพัลส์กับสถานะเดิม ในรอบสแกนที่มีพัลส์ Y1 จะกลับสถานะหนึ่งครั้ง
และรอบอื่นคงสถานะเดิม PLC FX5 ยังมีคำสั่ง ALTP
ที่สลับสถานะบิตทุกครั้งที่เงื่อนไขขึ้นขอบขาขึ้นให้ใช้ได้สะดวก

## 4.5 การออกแบบวงจรแจ้งเตือนและหยุดฉุกเฉิน

### 4.5.1 สวิตช์หยุดฉุกเฉินและหลัก Fail-safe

สวิตช์หยุดฉุกเฉิน (Emergency stop) เป็นปุ่มกดหัวเห็ดสีแดงบนพื้นสีเหลือง
เมื่อกดจะล็อกค้างจนกว่าจะบิดคลาย หน้าสัมผัสที่ใช้เป็นแบบ NC ที่เปิดออกแบบบังคับ (Positive
opening) ดังนั้นในสภาวะปกติอินพุต X0 เป็น ON เมื่อกดหรือสายขาด X0 จะเป็น OFF
โปรแกรมจึงใช้หน้าสัมผัส NC ของ X0 (LDI X0) เป็นเงื่อนไขเหตุฉุกเฉิน และใช้หน้าสัมผัส NO
ของ X0 อนุกรมในทุกแถวที่สั่งให้เครื่องทำงาน

### 4.5.2 โครงสร้างโปรแกรมแจ้งเตือนเหตุฉุกเฉิน

โปรแกรมแจ้งเตือนเหตุฉุกเฉินที่ดีประกอบด้วย (1) แถวแจ้งเตือนด้วยหลอดกะพริบและบัซเซอร์เมื่อ
X0 = OFF (2) แถว RST หรือ ZRST ที่ล้างสถานะการทำงานทั้งหมดเมื่อเกิดเหตุฉุกเฉิน (3)
เงื่อนไข X0 อนุกรมในแถว SET ของการเริ่มทำงาน เพื่อห้ามเริ่มทำงานขณะยังกดสวิตช์ และ
(4) เมื่อคลายสวิตช์แล้ว เครื่องต้องไม่เริ่มทำงานเอง ผู้ปฏิบัติงานต้องกด RESET หรือ START
ใหม่ ทั้งนี้ตามมาตรฐาน IEC 60204-1
การหยุดฉุกเฉินจริงต้องตัดกำลังด้วยวงจรความปลอดภัยแยกจากโปรแกรม PLC ทั่วไป โปรแกรม

### สรุปท้ายใบความรู้

\- M = รีเลย์ภายใน (ค่าหายเมื่อไฟดับ) L = รีเลย์คงค่า SM = รีเลย์พิเศษที่ระบบกำหนดหน้าที่

\- SM400 ON ตลอด · SM402 ON รอบแรก · SM412 นาฬิกา 1 วินาที · SM5500 แกนที่ 1
กำลังทำงาน

\- SET ตั้งบิตค้าง RST ล้างบิต/ไทเมอร์/เคาน์เตอร์ ZRST ล้างเป็นช่วง
แถวหลังสุดชนะเมื่อทำงานพร้อมกัน

\- PLS = พัลส์ขอบขาขึ้น PLF = พัลส์ขอบขาลง ใช้กับวงจร Toggle และงานหนึ่งครั้งต่อการกด

\- สวิตช์หยุดฉุกเฉินต่อแบบ NC ใช้ LDI X0 แจ้งเตือน ใช้ LD X0 อนุกรมในแถวเริ่มงาน
คลายแล้วต้องไม่เริ่มเอง

## บทสรุป

นอกจากอินพุต X และเอาต์พุต Y แล้ว PLC มีอุปกรณ์บิตภายในหน่วยความจำสำหรับใช้ในโปรแกรม
ได้แก่ รีเลย์ภายใน (M) ซึ่งใช้เก็บสถานะกลางของโปรแกรม รีเลย์คงค่า (L)
ซึ่งจำสถานะไว้แม้ไฟฟ้าดับ และรีเลย์พิเศษ (SM) ซึ่งระบบกำหนดหน้าที่ไว้แล้ว เช่น SM400 เป็น
ON ตลอด SM402 เป็น ON เฉพาะรอบสแกนแรก และ SM412 เป็นนาฬิกาคาบ 1 วินาที คำสั่ง
SET ตั้งบิตให้เป็น ON ค้างไว้ และคำสั่ง RST ล้างบิตเป็น OFF ใช้แทนวงจรคงสถานะได้
ส่วนคำสั่ง PLS และ PLF สร้างพัลส์หนึ่งรอบสแกนที่ขอบขาขึ้นและขอบขาลงของสัญญาณ
ผู้เรียนต้องเลือกใช้อุปกรณ์และคำสั่งเหล่านี้อย่างเหมาะสม
เขียนโปรแกรมแจ้งเตือนเหตุฉุกเฉินที่ปลอดภัย และเข้าใจผลของลำดับแถวคำสั่งเมื่อ SET และ
RST ทำงานพร้อมกัน

## แบบฝึกหัดท้ายหน่วยเรียน

คำชี้แจง: ให้นักศึกษาตอบคำถามต่อไปนี้ให้ถูกต้อง (10 ข้อ)

**1. จงเปรียบเทียบอุปกรณ์ X, Y, M, L และ SM ในด้านการเชื่อมต่อภายนอกและค่าเมื่อไฟดับ**

<details><summary>เฉลย</summary>

X: รับสัญญาณจากขั้วอินพุต อ่านใหม่ทุกรอบ

Y: สั่งขั้วเอาต์พุต ดับเมื่อไฟดับ

M: ภายในเท่านั้น ค่าหาย

L: ภายใน คงค่า

SM: ระบบกำหนดหน้าที่

</details>

**2. จงอธิบายข้อดีของการใช้รีเลย์ภายในเป็นตัวกลางแทนการเขียนเงื่อนไขซ้ำที่ทุกเอาต์พุต**

<details><summary>เฉลย</summary>

แก้ไขเงื่อนไขได้ที่จุดเดียว

นำสถานะไปใช้ได้หลายแถวไม่จำกัด

แยกตรรกะออกจากเอาต์พุตจริง ทำให้อ่านและตรวจสอบง่าย

ลดความผิดพลาดจาก Double coil

</details>

**3. จงเขียนโปรแกรมให้ M10 เก็บสถานะ RUN (START = X3, STOP = X4 ต่อแบบ NO) และ LAMP Y (Y3) ติดเมื่อ RUN และสวิตช์ทางเลือกอยู่ตรงกลาง (X1 = 0, X2 = 0)**

<details><summary>เฉลย</summary>

แถวที่ 0: LD X3, OR M10, ANI X4, OUT M10

แถวที่ 1: LD M10, ANI X1, ANI X2, OUT Y3

</details>

**4. จงอธิบายหน้าที่ของ SM400, SM402 และ SM412 พร้อมยกตัวอย่างการใช้งานอย่างละ 1 ตัวอย่าง**

<details><summary>เฉลย</summary>

SM400 ON ตลอด เช่น เงื่อนไขคำสั่ง MOV ที่ต้องทำทุกรอบ

SM402 ON รอบแรก เช่น ZRST ล้างขั้นการทำงานเมื่อเริ่ม RUN

SM412 นาฬิกา 1 วินาที เช่น หลอดเตือนกะพริบ

</details>

**5. ถ้าเขียน LD X3 SET Y1 ไว้ที่แถวที่ 5 และ LD X4 RST Y1 ไว้ที่แถวที่ 2 เมื่อกด X3 และ X4 พร้อมกัน Y1 จะเป็นอย่างไร และควรแก้ไขอย่างไรให้ปลอดภัย**

<details><summary>เฉลย</summary>

Y1 = ON เพราะแถว SET (แถวที่ 5) อยู่หลัง RST

ควรย้ายแถว RST ไว้หลังแถว SET หรือเพิ่ม ANI X4 ในแถว SET เพื่อให้การหยุดมีความสำคัญกว่า

</details>

**6. จงเขียนโปรแกรมวงจร Toggle ให้ปุ่ม X3 กดครั้งแรก Y1 ติด กดครั้งที่สอง Y1 ดับ**

<details><summary>เฉลย</summary>

แถวที่ 0: LD X3, PLS M0

แถวที่ 1: ใช้สมการ Y1 = M0·Y̅1 + M̅0·Y1 เขียนเป็น LD M0, ANI Y1, LDI M0, AND Y1, ORB, OUT Y1

หรือเขียนแบบสั้นด้วย LD X3, ALTP Y1

</details>

**7. จงวาดผังเวลาของ X3, PLS M0 และ PLF M1 เมื่อกด X3 ค้าง 2 วินาทีแล้วปล่อย**

<details><summary>เฉลย</summary>

X3: ON 2 วินาที

M0: ON หนึ่งรอบสแกนที่จังหวะเริ่มกด

M1: ON หนึ่งรอบสแกนที่จังหวะปล่อยปุ่ม

</details>

**8. จงเขียนโปรแกรมแจ้งเตือนฉุกเฉิน: เมื่อกดสวิตช์ฉุกเฉิน (X0, NC) ให้ Y4 กะพริบ Y5 ดัง และล้าง M10 ถึง M20 ทั้งหมด**

<details><summary>เฉลย</summary>

แถวที่ 0: LDI X0, AND SM412, OUT Y4

แถวที่ 1: LDI X0, OUT Y5

แถวที่ 2: LDI X0, ZRST M10 M20

</details>

**9. เหตุใดหลังคลายสวิตช์หยุดฉุกเฉินแล้วเครื่องจักรจึงไม่ควรเริ่มทำงานเอง และโปรแกรมต้องออกแบบอย่างไร**

<details><summary>เฉลย</summary>

การเริ่มทำงานเองอาจทำให้ผู้ที่กำลังแก้ไขปัญหาได้รับอันตราย

โปรแกรมต้อง RST สถานะการทำงานเมื่อเกิดเหตุฉุกเฉิน และต้องกด START หรือ RESET ใหม่จึงจะทำงาน

</details>

**10. เครื่องจักรต้องจำโหมด AUTO ที่ผู้ใช้เลือกไว้เมื่อไฟดับ แต่ห้ามเริ่มทำงานเอง จงออกแบบการใช้ L และ M**

<details><summary>เฉลย</summary>

เก็บโหมดไว้ใน L0 ด้วย SET/RST ตามการเลือกโหมด

สถานะ RUN เก็บใน M10 แบบคงสถานะด้วย OUT ซึ่งหายเมื่อไฟดับ

เงื่อนไขทำงานอัตโนมัติ = L0·M10 จึงต้องกด START ใหม่หลังไฟกลับมา

</details>
